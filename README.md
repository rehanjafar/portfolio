# Rehan’s portfolio

A responsive, buildless portfolio inspired by the structure of jerryddi.com, with Work, About, and Play sections.

## Preview

Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 8000
```

Visit http://localhost:8000.

## Customize

Edit `index.html` to replace the introductory bio and illustrative sample projects with your own work. Project details open in accessible dialogs. The Play page includes a palette generator.

No dependencies or build step are required.

The visual match to the reference has not been verified in a rendered browser.
